Questions

Answers to common questions about genie. The manual has all the details.

Install and first start

Windows says "Windows protected your PC". Is genie safe?

The packages are not signed yet, so SmartScreen does not know them. Click More info, then Run anyway. The installer needs no administrator rights. It puts genie in your user folder, adds it to the Start menu and opens .genie session files in genie. Each package comes from the release workflow of the GitHub repository, which also tests it.

macOS does not open genie.

Open the disk image and drag genie to Applications. Open genie. If macOS stops it, open System Settings > Privacy & Security and click Open Anyway. The disk image runs on Apple silicon and Intel Macs with macOS 11 or later.

The AppImage does not start on Linux.

Make the file executable with chmod +x genie-*-linux-x86_64.AppImage. Some systems need FUSE 2, the libfuse2 package. You can also install the .deb package with sudo apt install ./genie_*_amd64.deb.

How do I use genie from a terminal?

On Windows, genie.exe has no console. Use genie-cli.exe from the same folder, for example genie-cli snapshot work.genie regions.bed pictures. On macOS, run /Applications/genie.app/Contents/MacOS/genie. On Linux, run genie after you install the .deb, or the AppImage.

Files and data

Which files does genie open?

Sequences in FASTA and 2bit; features in BED, GFF3, GTF and bigBed; reads in BAM and CRAM 3.0 and 3.1; variants in VCF and BCF; signal in bigWig, bedGraph and bedMethyl; Hi-C maps of Juicer; interactions in BEDPE and bigInteract; copy numbers in SEG; GWAS summary statistics; and tables with a tabix index. The Files page of the manual lists the details.

My file has no index. Can genie open it?

Yes. genie makes the index in its cache folder for BAM files, and for VCF, BED, GFF3, GTF and bedGraph files compressed with bgzip. Plain and gzip files of any size open too: genie makes a sorted copy, compressed with bgzip, in its cache folder. A file on the web without an index downloads into the cache first, up to 1 GB.

A file on the web does not open.
  • The server must send parts of files (HTTP range requests). Most file servers, Amazon S3 and Google Cloud Storage do.
  • The index must be next to the file, with the usual name, for example reads.bam.bai or calls.vcf.gz.tbi. A track hub can give a different index.
  • genie reads only public buckets. It does not sign requests for private buckets or Requester Pays buckets.
  • genie connects directly to the server. It does not use a proxy server.
Where does genie keep its files?

The cache folder keeps the genome files, the indexes and sorted copies that genie makes, and the files that it downloads:

  • Windows: %LOCALAPPDATA%\genie
  • macOS: ~/Library/Caches/genie
  • Linux: $XDG_CACHE_HOME/genie or ~/.cache/genie

The settings panel shows the space that the cache uses. Clear removes the copies and indexes. The settings, the recent files and the last session are in %APPDATA%\genie on Windows, ~/Library/Application Support/genie on macOS, and ~/.config/genie on Linux.

Can I use genie without a network connection?

Yes, for files on your computer. To use a genome offline, click the genome label left of the locus box, then click Use offline. genie downloads the full sequence into its cache folder (human: about 835 MB). Public UCSC tracks and files on the web need a network connection.

My track has 1 as the name of chromosome 1, but the genome has chr1.

genie matches the contig names of a file with the names of the genome, for example 1, chr1, NC_000001.11 and CM000663.2. The track shows on chr1 of hg38.

Updates and privacy

How does genie find new versions?

When genie starts, it asks GitHub for the newest release, at most once a day. If a newer version exists, a notice says so. Click Download to open the release page, then install the new version as usual. To stop the checks, open the settings and set Updates to Off.

Does genie send data about me?

No. genie has no telemetry. It connects to a server only to read a file that you open, the files of a genome or a UCSC track that you select, and the newest release on GitHub. The update request contains the version of genie and no other data.

Problems

How do I report a problem?

Open an issue on GitHub. Write the version of genie (the settings show it), your system, what you did, what you expected and what genie did. If you can, attach a small file that shows the problem.

How do I see more about what genie does?

genie writes warnings to stderr. To see more, set the variable GENIE_LOG to info, debug or trace before you start genie, for example GENIE_LOG=debug genie.
